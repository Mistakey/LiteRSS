# 不做收藏与稍后读

**决定（2026-09，用户裁定，项目 LiteRSS 重做）：收藏、稍后读及对应的侧栏视图全部删除；同步不读也不写 FreshRSS 星标。**

## 为什么否决

LiteRSS 只服务一条动线：未读列表 → 扫中文标题 → 点开 → 值得细读或剪藏的去浏览器 → 已读。动线里没有「先存起来以后再看」这一步。
用户实际几乎不用收藏和稍后读：不愿在阅读器、浏览器、剪藏工具几处重复收藏，细读和剪藏都在浏览器里完成。

留着它的代价不小：每个同步周期要多拉一遍星标集、下载星标条目的正文、排队推送星标意图，本地还要维护
`server_starred` 镜像；侧栏多两个视图，文章右键和详情页多两个按钮，都要随新同步模型重写。

## 因此

- 同步周期不拉星标集，意图表只有已读一种；服务端的星标原样保留，LiteRSS 既不显示也不修改。
- 旧库导入时，未同步队列里的星标操作直接丢弃。
- 想留下一篇文章，就「在浏览器打开」，用浏览器的书签或剪藏工具。
