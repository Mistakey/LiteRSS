# 代理改为三态，默认跟随操作系统

> Source: mrrss-275349 (D13)；spec 原文 `git show fe3c371b:docs/tracker/closed/2026-08/精简自用版/spec.md`

MrRSS 原本的代理设置是一个布尔开关 `proxy_enabled` 加一组手填地址。关着的时候 Go 后端完全裸连——`httputil.CreateHTTPClient` 构造自定义 `http.Transport` 却把 `Proxy` 字段留空，连环境变量都不读。而用户的 Clash Verge 走的是 Windows Internet Settings（已核实：`ProxyEnable=1`、`ProxyServer=127.0.0.1:7897`，网卡列表无 TUN 虚拟网卡），Go 的 `net/http` 不读它。同一个应用里，WebView2（Chromium）读系统代理、Go 不读，两侧行为长期不一致。

2026-08-27 改成三态 `proxy_mode`：`system`（默认）/ `direct` / `manual`。`system` 用 [`mattn/go-ieproxy`](https://github.com/mattn/go-ieproxy) 读系统配置（Windows 走 WinHTTP/注册表，macOS 走 CFNetwork，Linux 读环境变量），并把结果装到 `http.Transport.Proxy` 上。这与 Firefox（默认「使用系统代理设置」）、RSS Guard（默认 Qt/系统代理）、Telegram Desktop（默认「使用系统代理设置」）一致。

## 被否决的方案

**让用户自己设 `HTTP_PROXY` 环境变量。** 零代码，但把「读系统设置」这件应用自己能做的事推给了用户，而且与上面三个参照实现的做法相悖。用户切一次代理工具就要改一次环境变量并重启应用。

**学 Miniflux 做逐源 opt-in 代理**（`HTTP_CLIENT_PROXY` 仅在订阅源勾选 "Fetch via proxy" 时生效）。[ADR 0002](0002-定位为纯-FreshRSS-客户端.md) 之后本地不抓 feed，需要代理的只剩全文抓取与翻译 / AI 调用，没有「逐源」的挂载位置。

**保留逐源代理字段作为灵活性。** `feeds.proxy_url` / `feeds.proxy_enabled` 两列已随本次改造删除：订阅源编辑表单在纯 FreshRSS 化时就没了，101 个源的值全为默认，它们只能通过手工拼请求写入。

## 后果

- **默认行为变了：升级后后端会开始走系统代理。** 迁移把 `proxy_enabled=true` 映射为 `manual`，其余映射为 `system`——包括原本显式关掉代理的情况。想要旧的裸连行为请选 `direct`。
- **`httputil.CreateHTTPClient(timeout)` 是唯一入口。** 全文抓取、百度与 AI 翻译、AI 摘要、AI profile 测连、更新检查全部经它；写裸 `&http.Client{}` 等于静默地退出了这个设置。改造前这里有六份各自读 `proxy_enabled` 的重复实现，其中翻译的两个 provider 构造器（`factory.go` 真正在用的那两个）压根没接代理。
- 新增一个 0.0.x 依赖 `go-ieproxy` v0.0.12（2024-05，久未更新）。权衡依据：它被 Azure AzCopy 用于生产，所依赖的 Windows / macOS 系统 API 长期稳定；且接入面就一个 `SystemProxy()`，要换很容易。
- **FreshRSS 同步不走这条路。** `internal/freshrss/client.go` 保留自己的 `http.Client`。FreshRSS 在局域网（`http://192.168.1.15:11181`），而 go-ieproxy 不认 Windows 绕过列表里 `192.168.*` 这种通配语法，实测该地址会被解析到代理。请求实际仍能到达（实测两边都拿到 FreshRSS 的 HTTP 400，31 ms 直连 vs 18 ms 经代理），因为 Clash 自己有私网直连规则——但那是「代理工具配得好」，不是 MrRSS 要求的。局域网服务器没有经外网代理的理由，核心同步路径也不应依赖别人的规则集。共享客户端只管外网出口。
- **不支持 PAC 脚本。** 用户的 Clash Verge 是静态系统代理，`go-ieproxy` 的静态路径已覆盖。
- 图片（前端 WebView2）与后端请求的代理行为自此一致，这也是 [ADR 0003](0003-不代理图片改由前端直连.md) 成立的前提。
